# QuizLab

Статическое портфолио с тремя интерактивными демо. Для запуска откройте `index.html` в браузере или запустите из папки проекта `python3 -m http.server 8000` и откройте http://localhost:8000.

## Редактирование

Все вопросы, ответы и результаты находятся в `js/config.js`. В Education поле `correct` — индекс правильного ответа, начиная с нуля; `levels` содержит максимальное число правильных ответов для каждого уровня, по возрастанию. При изменении числа вопросов обновите границы уровней. В Selector и Funnel каждый ответ может содержать `scores` — баллы для ключей курсов или сегментов. Побеждает наибольшая сумма; при равенстве приоритет у первого элемента в `courses` или `segments`. Добавляйте курсы и сегменты вместе с соответствующими баллами в ответах. Поле `format` в третьем и четвёртом вопросах Selector отображается в рекомендации. Тексты, стили и контакты можно менять в HTML и CSS.

Форма Funnel демонстрационная: данные не сохраняются и не отправляются. Для реального сбора заявок потребуется отдельная интеграция и соответствующее уведомление пользователей.

## Публикация на GitHub Pages

Загрузите файлы в репозиторий, откройте Settings → Pages, выберите Deploy from a branch, ветку и корневую папку `/ (root)`, затем сохраните. GitHub покажет адрес опубликованного сайта. Все ссылки внутри сайта относительные и работают в репозитории на GitHub Pages.
